# Загальна карта

Опис: Insight Professional — італійський бренд органічної косметики для волосся, виробляється в Італії компанією з понад 70-річним досвідом. Ідея бренду — «свідома краса»: ефективний догляд на основі рослинних екстрактів та олій, без шкоди для здоров'я і довкілля. Представлений у 50+ країнах.

Три опори бренду, які варто запам'ятати:

- **Натуральність складу** — формули на основі органічних фітоекстрактів. Без SLS/SLES, парабенів, силіконів, вазеліну (нафтопродуктів), синтетичних барвників. Багато засобів nickel-tested (протестовані на нікель) — тому підходять чутливій шкірі.
- **Сертифікації** — Cosmos Natural, VeganOK (веган, не тестується на тваринах), ICEA/Ecocert. Це не просто «напис натурально», а офіційне підтвердження.
- **Екологічність** — скляна й алюмінієва упаковка, відповідально видобуті інгредієнти, еко-виробництво.

# Лінійки продукції поділені на основні проблеми

**1. Догляд за шкірою голови (проблема — шкіра)**

- **Lenitive** — заспокоює почервоніння й подразнення (чутлива шкіра). *Опунція + алое + мальва. Cosmos Natural.*
- **Sensitive** — делікатне очищення чутливої шкіри, для всієї родини, щоденно. *Айва + гарбуз. Cosmos Natural.*
- **Clarifying** — проти лупи, нормалізує баланс. *Шавлія + чебрець + розмарин.*
- **Rebalancing** — баланс і детокс, глина проти себуму. *Мікроводорості + береза + лаванда.*
- **Densifying** — проти випадіння й витончення, мікроциркуляція. *Кінський каштан + гуарана + настурція.*

**2. Догляд за типом/станом волосся (проблема — волосся)**

- **Volumizing** — об'єм тонкого волосся без обтяження. *Женьшень + псіліум + біла кропива.*
- **Anti-frizz** — проти пухнастості, зволоження + розгладження. *Амарант + льон + бавовна.*
- **Elasti-curl** — кучері: чіткість і еластичність завитка, антифриз. *Кокос + чіа + сача інчі.*
- **Dry Hair** — глибоке живлення сухого/ламкого. *Овес + ілліпе + кокос.*
- **Damaged Hair** — відновлення після хімії/термо/сезону. *Пшениця + олива + арган.*

**3. Колір**

- **Blonde** — нейтралізує жовтизну, холодний блонд. *Екстракт каштану.*
- **Colored Hair** — захист кольору фарбованого, проти вимивання. *Хна + манго + макадамія.*

**4. Універсальні**

- **Daily Use** — щоденне очищення, усі типи, є тревел-версія. *Лимон + абрикос + кукурудза.*
- **Antioxidant** — захист від довкілля (хлор, море, забруднення). *Морква + соя + фундук.*
