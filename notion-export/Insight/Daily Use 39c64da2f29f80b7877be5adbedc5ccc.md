1. Енергезуючий шампунь

![image.png](image%2015.png)

Дбайливо та ефективно очищає, допомагаючи відновити зволоження і блиск навіть дуже сухого волосся. Підходить для всіх типів волосся.

Активні інгредієнти:

- органічний екстракт лимона
- масло абрикосових кісточок
- олія зародків кукурудзи

1. Сухий шампунь для об`єму

![image.png](image%2016.png)

Сухий шампунь у пудрі, що абсорбує надлишок себуму між миттям волосся. Миттєво освіжає шкіру голови та надає об’єму без обтяження. Підходить для всіх типів волосся.

Активні інгредієнти:

- органічна олія німу
- екстракт фітопланктону

1. Енергетичний кондиціонер для волосся

![image.png](image%2017.png)

Кондиціонер із зволожувальною дією, який живить волосся по всій довжині, не обтяжуючи його. Рослинні олії у складі надають волоссю м’якість і природний блиск. Засіб підтримує природний рівень зволоження волосся та миттєво полегшує розчісування.

Активні інгредієнти:

- органічний екстракт лимона
- масло абрикосових кісточок
- олія зародків кукурудзи

1. Незмивний кондиціонер для розплутування волосся

![image.png](image%2018.png)

Зволожувальний спрей-кондиціонер без змивання, який забезпечує зволоження без обтяження волосся. Підходить для щоденного використання, миттєво полегшує розчісування та дарує волоссю необхідне зволоження.

Активні інгредієнти:

- органічний екстракт лимона
- масло абрикосових кісточок
- олія зародків кукурудзи

1. Енергетична маска для волосся

![image.png](image%2019.png)

Відновлювальна маска для щоденного зволоження. Підходить навіть для тонкого волосся, оскільки не обтяжує його. Полегшує розчісування, надає волоссю блиск, м’якість і робить його більш слухняним.

Активні інгредієнти:

- органічний екстракт лимона
- масло абрикосових кісточок
- олія зародків кукурудзи
