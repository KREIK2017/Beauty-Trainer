# Lifestyling

Опис: Серія для захисту, фіксації та
створення стійких укладок
Підходить для:  всіх типів волосся та будь-яких укладок
Фото: image.png

Thermo Protector: термозахист для волосся під час
укладки

Eco Strong Hairspray: еко-лак сильної фіксації без
обтяження

Shaping Foam: пінка для укладки сильної фіксації

Volumizing Foam: термозахисна пінка для обʼєму та
моделювання зачіски

Ключові інгредієнти: молочні білки, білки кіноа
